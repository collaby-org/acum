The stream path: a channel in, a picture out

The browser never names an upstream address. It asks for a channel; the server resolves the feeds from the catalogue and hands back a signed manifest; every byte after that travels through /api/stream under a token that carries the address. The catalogue is the only place an address is written down, and the allowlist is exact.

Source of truth: monorepo/frontend/src/app/api/player/route.ts, monorepo/frontend/src/app/api/stream/route.ts, monorepo/frontend/src/lib/stream.ts. The same picture is written in Mermaid in docs/diagrams/stream-path.md so it renders on GitHub. Type is set in Space Grotesk and Inter with the platform's own faces as the fallback — the file loads nothing from the network.
